# 🗺️ Mapa de Calor de Acidentes de Trânsito

## 📌 Sobre o projeto

Neste projeto, eu desenvolvi uma análise geográfica de acidentes de trânsito utilizando dados simulados mais robustos, representando múltiplas cidades brasileiras.

O foco foi identificar padrões espaciais e regiões com maior concentração de acidentes.

---

## 🎯 Objetivos

- Visualizar acidentes geograficamente
- Identificar hotspots
- Analisar gravidade dos acidentes
- Explorar dados temporais

---

## 🧠 Habilidades desenvolvidas

- Análise exploratória (EDA)
- Visualização geográfica com Folium
- Manipulação de dados com Pandas
- Análise espacial

---

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Folium
- NumPy
- Google Colab

---

## 🌎 Diferencial do projeto

Neste projeto, eu utilizei um dataset mais robusto contendo:

- Múltiplas cidades
- Diferentes tipos de acidentes
- Níveis de gravidade
- Informações de data e hora

---

## 📊 Principais análises

- Heatmap geral de acidentes
- Heatmap de acidentes graves
- Distribuição por cidade
- Análise temporal
